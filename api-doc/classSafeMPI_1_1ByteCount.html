Detailed Description

The (count, datatype) pair that describes a buffer of bytes to MPI.

This is how a buffer of more than INT_MAX bytes is sent and received where MPI has no large-count functions (before MPI 4), see Intracomm::Isend_bytes() . MPI counts are int , so a buffer of more than INT_MAX bytes cannot be described as a count of MPI_BYTE . Such a buffer is described here as one element of a derived datatype: whole chunks of bytes, then the bytes left over. The type signature is that of the same number of MPI_BYTE , so the two ends of a message need not agree on how they describe it. A derived datatype is freed by the destructor; MPI lets a datatype be freed while a nonblocking operation that uses it is pending, so the object need not outlive the request.

This exists for tests, which lower it to take the derived-datatype path with small buffers; nothing else has a reason to call it. The two ends of a message may use different values, and a change while messages are in flight is safe: each ByteCount reads the value once.
