◆ nuclear_density_reach()

double madness::Molecule::nuclear_density_reach ( std::size_t i,
double rscale = 1. ) const
Parameters
ithe index of the atom
rscaleas in nuclear_charge_density()
Returns
the distance from atom i beyond which its nuclear charge density vanishes; 0 for an uncharged (ghost) atom, which has no density. Its smoothing radius stays finite (1 bohr by default) since rcut also enters the smoothed potential, where rcut = inf would make 0*inf. Follows the current q and rcut, as the density does; note that set_atom_charge() does not update rcut.
Exceptions
MadnessExceptionif the reach of a charged atom is not finite and positive (e.g. a negative charge, for which rcut is NaN)
