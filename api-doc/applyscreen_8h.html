Detailed Description

Destination screening of the apply of an integral operator.

The result of an apply is often multiplied with another function afterwards (the exchange operator: K f = sum_i ket_i * P(bra_i f)). A contribution to a box in which that multiplier is negligible is then never used, and need not be computed (Yanai, Fann, Gan, Harrison, Beylkin, JCP 121, 6680 (2004), eq. 17). A screen answers, per destination box, a bound on the multiplier's largest magnitude there (supbound.h). FunctionImpl::do_apply skips a block whose contribution times that bound, capped at one, is negligible, computes a kept block with its per-term tolerance loosened by the same factor, and accumulates it only if its norm times the factor is significant; a skipped block still counts as used by the shell loop. A skipped block leaves at most the block's share of the tolerance in the product function, since ||s du||_2 <= sup|s| ||du||_2. The tasks of one apply carry the screen (ApplyScreenHandle; apply_only, and the vector apply(world, op, f, screens)); without one, do_apply is unchanged.
