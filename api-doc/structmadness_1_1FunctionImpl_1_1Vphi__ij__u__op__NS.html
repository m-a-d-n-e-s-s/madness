Detailed Description

template<typename T, std::size_t NDIM>
template<typename opT, size_t LDIM>
struct madness::FunctionImpl< T, NDIM >::Vphi_ij_u_op_NS< opT, LDIM >

adaptive multiplication of u(1,2) by optional orbitals i(1) and/or j(2), with optional contraction against an exact ERI g(1,2) Modes (controlled by which pointers are non-null):

  • function mode (eri==null): builds result = u * [i(1)] * [j(2)] into *result
  • inner mode (eri!=null): computes <eri | u * [i(1)] * [j(2)]>, accumulates scalar at result->cdata.key0

Error control: d-norm cross terms (inaccurate refinement, from CoeffTracker::dnorm) plus tnorm error from each pointwise_multiplier application. Replaces multiply_op<LDIM> (adds d-norm error) and do_inner_local_on_demand (adds inaccurate-refinement error and adaptive NS-form traversal).

template<typename T, std::size_t NDIM>
template<typename opT, size_t LDIM>
std::pair< coeffT, double > madness::FunctionImpl< T, NDIM >::Vphi_ij_u_op_NS< opT, LDIM >::make_sum_coeffs ( const keyT & key) const

multiplicative chain: current = u → u·i(1) → u·i(1)·j(2)

Inputs are expected in redundant tree state (cheap to construct from reconstructed, avoids the expensive compress/nonstandard round-trip). In that state CoeffTracker::coeff(key) calls parent_to_child and returns scaling-function coefficients of shape [k]^NDIM, exactly what pointwise_multiplier consumes.

Past a leaf the CoeffTracker pins key_ to the leaf, so coeff(key) interpolates the leaf's [k]^NDIM s-coeffs to the requested level — equivalent to embedding them in a [2k]^NDIM NS tensor (s-part filled, d-part zero) and unfiltering. d-norms past the leaf are zero, which falls out of CoeffTracker::dnorm.
