Detailed Description

An array of more than 2^32 elements through the buffer and vector archives.

The count of an array used to be an unsigned int, so such an array was cut to its size modulo 2^32 when stored, with no error. Takes about 13 GiB, so the test carries the "large" label; test_ar.cc checks the count alone, which takes no memory.
