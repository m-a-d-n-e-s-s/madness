compute all potentials applied on nemo, without the weak-form split

The pre-weak-form signature, kept for callers that have no use for the flux. It never opts in to the weak form, whatever xc_weak_gga says, so xcnemo always carries the complete multiplicative xc potential and the xc block of the Fock matrix can be read off it as before. Silently discarding xcflux instead would drop the semilocal term.
