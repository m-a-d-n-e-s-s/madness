Detailed Description

template<typename T, std::size_t NDIM, std::size_t LDIM = NDIM/2>
struct madness::LowRankFunctionFactory< T, NDIM, LDIM >::ProjectionState

State for the stable power-iteration projection. Stores h_raw and its overlap for incremental tol-tightening on <h|h>.
