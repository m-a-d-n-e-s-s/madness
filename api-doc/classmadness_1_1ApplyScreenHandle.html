Detailed Description

template<std::size_t NDIM>
class madness::ApplyScreenHandle< NDIM >

The screen as the tasks of an apply carry it: shared ownership, so the screen lives as long as any task of the apply does, and nothing is stored on the function. Empty means no screen. The tasks stay on the rank that creates them (apply_only refuses apply_randomize), so the handle does not travel.
