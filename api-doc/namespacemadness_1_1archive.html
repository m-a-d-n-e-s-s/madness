◆ ContainerRecordTag

enum madness::archive::ContainerRecordTag : unsigned char

Tag byte that starts every framed record (see ContainerRecordOutputArchive::close).

A record larger than the RMI INT_MAX message limit cannot be sent through WorldContainer::replace in one piece, so it is split: the record at key becomes a header [RECORD_CHUNKED][total][nchunk] and the payload is stored as nchunk records [RECORD_CHUNK][key][i][slice] at container_record_chunk_key(key, i). Any other record is [RECORD_INLINE][payload], so the tag alone tells the reader which it is.

Chunk keys share the container's key space, so a chunk can still collide with an unrelated record. That is unlikely (64-bit keys) but not prevented: ruling it out would need an existence check on the remote owner, and WorldContainer's only remote lookup, find(), copies the value, which may itself exceed 2 GiB. A collision is detected instead: each chunk names its record and index, so the reader throws rather than returning another record's bytes.

Records are write-once: a key holding a chunked record must be freed with erase_container_record() before it is written again, or the old chunks stay allocated (not checked, for the same reason). The cloud never rewrites a key.

An unframed record (framed=false) is the bare payload, never chunked: for containers whose bytes are read directly rather than through ContainerRecordInputArchive (the cloud's batch container, which has its own chunked transport). Framed and unframed records must not share a container.

◆ container_record_chunk_key()

long madness::archive::container_record_chunk_key ( const long key,
const std::uint64_t ichunk )
inline

Key of chunk ichunk of the chunked record at key: hashed, not key+1, key+2, …, so a chunk cannot land on a neighbouring record whose key a caller chose sequentially.

A full 64-bit mix (splitmix64's finalizer, a bijection), not worldhash's hash_value, which folds a long to 32 bits: two records whose keys agreed in those 32 bits would get identical chunk keys.

References mix.

Referenced by madness::archive::ContainerRecordOutputArchive::close(), erase_container_record(), and madness::archive::ContainerRecordInputArchive::load_chunks().
