Detailed Description

template<std::size_t NDIM>
class madness::SupBoundScreen< NDIM >

The screen built from the multipliers' sup bounds (SupBoundMap, FunctionImpl::sup_bound_map): the largest of their bounds in the box. A box none of the maps holds (not local to this rank, or without coefficients) answers unbounded, which screens nothing.
