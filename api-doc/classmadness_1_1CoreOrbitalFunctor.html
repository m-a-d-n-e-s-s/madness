Detailed Description

Functor for evaluating a core orbital of a specific atom in a molecule.

This class implements the FunctionFunctorInterface for evaluating the value of a core orbital at a given 3D coordinate. It holds references to a molecule, the atom index, the core orbital index, and the magnetic quantum number m.
