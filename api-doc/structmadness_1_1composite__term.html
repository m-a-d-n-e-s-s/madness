Detailed Description

template<typename T, std::size_t NDIM>
struct madness::composite_term< T, NDIM >

One term of a composite product: ket(1,2) * factor1(1) * factor2(2) * extra(1,2)

The ket is either an explicit NDIM Function (ket) or a low-rank sum of hartree products ket(1,2) = Σ_k p1[k](1) ⊗ p2[k](2). Provide ket or (p1, p2); not both.
