Detailed Description

Options for the three-range LRF k-commutator variant. Partition the Coulomb GFit into:

  • diffuse (α_μ < alpha_lo): wide Gaussians, large-ve LRF, low rank
  • medium (alpha_lo ≤ α_μ ≤ alpha_hi): tighter LRF
  • tight (α_μ > alpha_hi): discard (δ-cancellation in commutator) See lrf_three_range_gfit.md for the derivation.

bool madness::ExchangeCommutator::ThreeRangeOptions::medium_use_6d = false

If true, the medium slab is treated by a 6D apply with a partial-Coulomb operator (only the medium Gaussians) instead of any LRF. The diffuse slab still uses the LRF path. Mutually exclusive with medium_use_taylor; takes precedence.
