Detailed Description

Counters of the apply screen, process-wide: the blocks that passed the source test while a screen was installed and the ones it skipped, and the sup bounds built for screens with the time it took. Reset and reported by whoever installs the screens (the exchange operator, summed over the ranks); a caller that runs the exchange tasks in its own queue reports after the queue ran.
