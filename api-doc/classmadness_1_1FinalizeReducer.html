Detailed Description

template<typename T, std::size_t NDIM>
class madness::FinalizeReducer< T, NDIM >

Receiving end of the exchange finalize, living in the world the transfer rides on.

Sources push bulk chunks here with task(), so deserializing and accumulating happens on a worker and never on the communication thread. The arithmetic is the same as FunctionNode::gaxpy_inplace; the accessor write lock is what serializes two senders that reach the same key at once.
